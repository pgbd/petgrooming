# ADR-0007: Phase A document names win

Status: Accepted
Resolves contradiction C7 (see [Plan.md](../Plan.md)).
Approved: in the project session, on the user's explicit confirmation of the proposed decisions. G0 sign-off by Vaiya and the owner still applies and may revise this record.

## Context

Earlier advice listed files such as product-spec, architecture, data-model and test-plan. The plan's Phase A names PRD, AppFlow, UI_Spec, TRD, Schema and Plan.

## Decision

The Phase A names are authoritative. The earlier names are superseded. Further documents, such as runbook and project-status, are created only when needed.

## Consequences

docs/README.md is the index. No parallel documents duplicate the six.
